## The backend uses FastAPI and loads:
- occupancy prediction models (XGBoost / Random Forest)
- ETA prediction model
- WebSocket support for live updates
## The frontend is a web dashboard using:
- HTML/CSS
- Leaflet maps
- Real-time bus visualization
## The raspberry-pi simulator sends simulated bus data to the backend periodically.
